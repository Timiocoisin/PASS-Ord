# Numeric evidence and logs

The MIT license applies to project source code and its documentation. It does not grant a license to raw experimental images, model weights, numeric evidence, or retained logs.

Files in `evidence/` and `logs/` are made publicly accessible to permit inspection and verification of the reported computations. No additional data redistribution or commercial-use license is granted by this release. Contact the repository maintainer through GitHub for questions about additional permissions.

Raw images, binary feature caches, and checkpoints are not distributed. Split manifests contain relative image identifiers and acquisition metadata, not the image content. Local machine paths in the selected logs were replaced with `<LOCAL_PATH>`; numeric entries were not changed. Historical filenames and experiment labels are retained as provenance, not as publication claims.
